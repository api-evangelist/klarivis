# KlariVis

> Enterprise data analytics platform for community banks and credit unions. KlariVis
> ingests data nightly from an institution's core and ancillary systems into a secure
> Microsoft Azure data warehouse, then aggregates and visualizes it in role-based
> interactive dashboards and reports. Founded 2019 in Roanoke, Virginia by Kim Snyder;
> $11M Series B led by Blueprint Equity (January 2024); 100+ financial institutions.

## Agent-relevant status

KlariVis publishes **no public API**. As of 2026-08-23 there is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server, no A2A agent
card, no SDK on any public package registry, no public GitHub organization, and no
`/.well-known/` document on any KlariVis host. `api.klarivis.com`,
`docs.klarivis.com` and `developer.klarivis.com` do not resolve (NXDOMAIN).

KlariVis is a **consumer** of banking core and ancillary system APIs, not a publisher
of one. Integration with an institution's core is performed by the KlariVis
implementation team as part of onboarding, not through self-service developer
credentials. An agent cannot call KlariVis programmatically today; the only published
entry points are a demo request form and a login-gated customer support portal.
